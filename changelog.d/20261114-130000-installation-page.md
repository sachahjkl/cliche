**cliche installs itself: an Installation page in the settings.** It says where the installed copy is, its version, whether this copy is the installed one, the menu entry, Settings > Apps, the start with the session and the PATH, with Install, Repair, Upgrade and Uninstall. On Windows a copy that is not installed offers it when its window first shows. The command line has `--install`, `--uninstall`, `--status` (what is installed, and whether cliche runs) and `--setup`, the same as in the other programs. The palette finds the page ("install").
