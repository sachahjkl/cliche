**cliche updates itself, as the other programs of Froment Software.** The installed copy looks for a new version a while after the start and then every day, checks its signature, and puts it in place; it starts again in the notification area as soon as no window is shown and nothing is under way. The settings have an Updates page: Update by itself, the state, Check now, Install and Restart now. The palette has "Check for updates". A copy run from the Nix store is left to Nix.
